# 班级排座位 · 在线版 v2（GitHub Pages + 实时同步）

本目录是 **GitHub Pages 静态网站**。v2 全新升级：**登录 + 角色权限 + 换座申请 + 班主任/管理员管理**，所有操作实时写入仓库 `docs/data/state.json`，多端自动同步。

## 登录方式
| 角色 | 姓名 | 学号 |
|---|---|---|
| 学生 | 名单内真实姓名 | 本人学号 |
| 班主任 | 崔孝禹（管理员可在后台改名） | 任意 |
| 管理员 | `admin` | 管理员密码（默认 `admin888`，可在后台修改） |

## 功能
- **座位显示**：登录后进入座位表，自己座位绿色高亮
- **换座申请（学生）**：点击其他同学座位 → 发起申请 → 对方登录后「同意」即完成互换 /「不同意」则不换
  - 讲台旁护法、固定同桌、单人单座 不可由学生申请互换（规则保护）
- **班主任规则**（班主任 + 管理员可用）：
  - 左右护法（讲台旁，最多 2 人）
  - 固定同桌、单人单座、不可为同桌
  - 强制互换（无视一切规则）
  - 生成排位 / 前后轮换 / 左右轮换（保女生列）/ 左右大组轮换
- **管理员**（`admin`）：
  - 修改班主任姓名
  - 修改管理员密码
  - 新增 / 删除 / 导入学生名单（支持 .xlsx/.csv）
  - 无视任何规则进行位置交换

## 同步原理
- **共享状态文件**：`docs/data/state.json`（`updated_at` / 座位网格 / 规则 / 待处理申请 / 名单 / 账号信息），唯一权威来源
- **所有写操作**（申请、同意、换座、规则、名单）通过 GitHub Contents API 原子写入，带 `sha` 冲突检测重试（并发安全）
- **多端同步**：前端每 5 秒轮询静态源（GitHub Pages + raw）+ 每 60 秒轮询 API，取 `updated_at` 最新版本渲染，别人换完座位约 1 分钟内即可看到

## 排座算法（Go 引擎，桌面版）
- 构造初始解 + 局部搜索优化（同性别内交换），支持固定规则：护法位、固定同桌、单人单座、不可同桌、女生列、两列一组
- 桌面版二进制见仓库 Release（Go 编译，跨平台）

## ⚠️ 安全提醒（重要）
- 仓库为**公开仓库**：① 学生名单公开可见；② 网站为纯静态托管，**学生端换座申请写入必须使用一个写凭据**，该凭据以混淆形式内嵌于 `app.js` 中，任何人查看网页源码即可提取——它只对该仓库有写权限，但请知悉此风险。
- **强烈建议**：将内嵌凭据替换为仅限本仓库的 **fine-grained token**（`app.js` 顶部 `WRITE_TOKEN` 处混淆替换），或改用带真实后端的方案。
- 班主任姓名、管理员密码均存储于公开的 `state.json`（密码为哈希值，姓名明文）——本工具定位为班级内部工具，如需更高安全等级请更换私有后端。
- 如需名单保密：换用私有仓库（则在线 Pages 版不可用）或自建服务器。
